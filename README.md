# Responsive Webpage

A simple responsive webpage developed using HTML5 semantic tags and CSS3.

## Files
- index.html
- style.css

## Features
- HTML5 semantic tags
- CSS3 styling
- Responsive design
- Mobile, tablet and desktop support
- Flexbox
- CSS Media Queries

## How to Run
Open `index.html` in any web browser.

## GitHub
Upload both `index.html` and `style.css` to a GitHub repository.
